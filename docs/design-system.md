# Latte Work 全局界面规范

这份规范约束应用导航、对话、设置、弹窗和菜单。视觉方向是安静、紧凑的深色桌面工作台：正文优先，工具执行记录保持轻量，操作控件不抢阅读注意力。

默认设计变量在 `apps/desktop/src/tokens.css`；外观设置通过 `appearance.ts` 生成颜色和字体覆盖值。组件布局和状态规则在 `style.css`，外观编辑器样式在 `appearance.css`。

## 颜色与层次

默认深色主题采用中性黑灰：主画布 #111111、侧栏约 #1A1A1A、菜单约 #232323、输入区约 #282828。默认主操作为浅灰白，Material 预设仍保留蓝灰配色；已保存的自定义主题不自动覆盖。

| 角色                   | Token                                                                       | 用途                       |
| ---------------------- | --------------------------------------------------------------------------- | -------------------------- |
| 主画布                 | `--color-canvas`                                                            | 对话和设置内容背景         |
| 侧栏                   | `--color-sidebar`                                                           | 项目导航、设置导航         |
| 面板                   | `--color-surface`                                                           | 弹窗、设置分组             |
| 浮层                   | `--color-elevated`                                                          | 右键菜单、下拉菜单         |
| 输入区                 | `--color-input` / `--color-composer`                                        | 表单输入与聊天输入         |
| 主要 / 次要 / 辅助文字 | `--color-text` / `--color-text-secondary` / `--color-text-muted`            | 正文、标签、说明           |
| 分隔 / 控件 / 浮层边界 | `--color-border-subtle` / `--color-border` / `--color-border-strong`        | 统一使用 1px 线            |
| 主操作                 | `--color-action` / `--color-on-action`                                      | 发送、表单确认使用中性黑白 |
| 停止                   | `--color-stop` / `--color-on-stop`                                          | 独立中性控制色、方形图标   |
| 强调                   | `--color-primary` / `--color-on-primary`                                    | 链接、外观调色控件         |
| 键盘焦点               | `--color-focus-background`                                                  | 中性透明背景，不增加描边   |
| 品牌                   | `--color-brand`                                                             | Logo、少量品牌装饰         |
| 状态                   | `--color-success` / `--color-warning` / `--color-danger` / `--color-unread` | 成功、等待、错误、未读     |

发送、弹窗和表单确认按钮使用中性操作色（`--color-action` / `--color-on-action`）：深色主题白底深字，浅色主题深底白字。停止使用独立中性控制色。悬停使用各自角色的颜色，禁用使用禁用色；主题强调色不改变这些操作按钮。

金色不用于通用按钮背景、默认选中框或输入焦点。状态色需配合文字或图标，不单靠颜色传达含义。禁用主按钮使用独立的背景和文字色，避免对整个按钮降低透明度后产生浑浊的金色。

浅色默认白色画布、菜单和输入区，浅灰侧栏与选中项，中性深色主操作；使用浅灰边界和低强度阴影分层，避免整块灰底。

## 字体与间距

- UI 使用系统字体栈；macOS 由系统字体和中文回退字体渲染。
- 聊天 Markdown 正文为 14px，一级标题 16px、二级标题 15px、其余标题 14px，以 600 字重区分；行高 1.75；段落间距 16px，列表项间距 4px。正文默认 400 字重，行内强调默认 500，保留 Markdown 的强调语义，避免大片文字过重。macOS 聊天正文使用抗锯齿渲染，外观预览与对话共用 Markdown 字体规则；用户设置的正文与代码字体、字重继续生效。表格为 13px，使用轻量横向分隔线，无竖线或外框；代码块为 13px。其他正文沿用 15px，UI 为 13px，表单标签为 12px，辅助信息最小为 11px。
- 分组标题为 16px，弹窗与设置标题为 20px。品牌和欢迎页可以有独立展示字号。
- UI 常规字重 400，选中项/强调 500，标题 600。不要通过全局加粗制造信息层级。
- 品牌名称统一写作 `Latte Work`，保持单行与轻重字重层次；品牌文字固定 18px，「Latte」为 500 字重、「Work」为 450 字重，窄窗口不放大。侧栏标记为 20×22px，与文字保持 8px 间距，不显示 PREVIEW 标签或底部标语。
- UI 行高 1.5；现有对话 Markdown 的阅读行高及标题层级独立保留。
- 间距使用 4、8、12、16、20、24、32px。弹窗内边距 24px；字段标签到输入框 8px；内容组之间 24px；按钮之间 8px。
- 正文、输入区和设置表单统一使用 `--content-width`（780px），对话两侧留白使用 `--content-gutter`；三栏可调尺寸、44px 标题栏和模型选择器的紧凑布局保留。光学对齐、品牌和旧布局尺寸允许少量例外；新增组件不另创一套尺度。

只有独立浮层使用明显投影；工具调用摘要仍是无边框行，展开内容在自己的滚动区域内阅读。用时、正文、工具图标和展开面板外边框共用左边线；工具组子项与审批结果不叠加横向缩进，面板内部保留阅读内边距。胶囊仅用于短标签、轻量添加操作；模型选择继续使用正文式按钮。

执行过程中的正文块与工具摘要之间统一使用 16px 留白，工具摘要最小高度 28px，保持轻量、连续的阅读节奏。正文内部沿用 1.75 倍行高和 16px 段落间距，最终回复操作区与相邻轮次保留各自的间距规则。

## 交互状态

- 默认：用结构、文字和细边框建立层次。
- 悬停：浅色透明底，不改变尺寸和布局。
- 选中：统一选中背景，和悬停、键盘焦点区分。
- 点击和聚焦：全局保持原有边框宽度、颜色和圆角；禁止新增 outline、焦点阴影或高亮描边，包括组合输入的 focus-within 状态。
- 键盘操作：按钮、选择器、summary 和可聚焦输出区使用中性透明背景提示焦点，保留原有底色和文字对比；菜单保留高亮项。文本输入通过光标和选区提示焦点，不改变输入容器边框。
- 禁用：使用可读的禁用文字与按钮底色，不对复合控件叠加 opacity；图标与文字同步，不得留下正常悬停反馈。
- 错误：明确显示原因；等待/加载状态提供文字或旋转图标；不改变控件占位。
- 动效：常规颜色过渡 150ms；尊重系统减少动态效果设置。
- 侧栏开关：展开时位于侧栏顶栏右端，靠近会话区；收起时位于主顶栏左端，旁边保留新对话按钮。两种状态使用同一 16px 图标与 32 × 28px 点击区域，垂直居中于 44px 顶栏。
- 收起时，鼠标在开关停留 200ms 后临时展开侧栏浮层，不占布局宽度、不修改已保存的展开状态；移出开关和浮层 150ms 后关闭。浮层中操作菜单或保有键盘焦点时保持展开，点击外部或 Escape 关闭。点击开关立即固定展开，浮层开关使用「固定侧栏」提示；对话和合并工作区共用此行为，尊重系统减少动态效果设置。
- 侧栏分组：标题和紧邻文字的 14px 箭头组成同一按钮，点击区域高度至少 28px；向右表示收起、向下表示展开。置顶、项目与最近独立记住状态，标题旁的添加操作独立响应；收起不改变当前会话或项目归属。分组内容共用侧栏滚动区，设置入口固定在底部。
- 「最近」位于项目下方，汇总本机与 SSH 主机上全部可见项目的未归档对话，按服务端记录的实际对话活动时间排序；置顶会话仅留在置顶分组。行沿用现有会话状态、菜单和打开流程，远程项显示与项目文件夹右下角一致的绿色经纬线图标，以约 0.9px 的轻量线条显示；颜色采用成功色 88% 与侧栏背景色混合，降低亮度与饱和度，使远程标记保持辅助层级。避免被通用按钮图标样式加粗，固定在行末并与归档按钮中心对齐；执行、失败、待确认及未读状态优先占用同一位置。悬停、键盘聚焦或菜单打开时隐藏标记并显示操作，不将标记挤向标题。同名时补充项目与主机信息。较早历史按主机继续加载，分页有界；失败保留已读取记录并提供重试，不显示推测的空历史。各项目的展开状态独立保留；切换项目、对话或展开最近不收起其他项目，打开最近记录或置顶对话不强制展开其项目列表，保留所有项目当前的展开状态；隐藏「最近」分组时也遵循此规则。启动不自动打开最近会话，也不因列表读取启动 Agent。
- 置顶只用于会话，项目使用文件夹图标和项目列表原始顺序，不提供项目置顶菜单。
- 置顶与最近的对话名称共用 8px 左内边距，文字左边线对齐；选中和悬停背景保持相同的行宽。
- 侧栏导航使用 macOS 字体抗锯齿；新任务、置顶、项目、最近、项目与对话为 14px。导航字重至少为 450，比常规略厚，用户选用更高 UI 字重时继续生效。侧栏左右内边距为 8px，分组标题行高 32px，上下间距分别为 12px / 4px；收起后不保留列表占位。“新任务”为 36px 高的无底色菜单项，使用细线编辑图标，只有悬停和键盘焦点反馈，不使用卡片边框；键盘快捷提示仅在悬停和键盘聚焦时出现，不改变布局。
- 项目和任务采用紧凑的单行列表，项目行高 31px，任务背景行高 30px；任务容器上下各留 1px，使相邻选中和悬停背景之间保持 2px 留白。项目、置顶和最近共用此间距，不额外叠加置顶行外边距，操作按钮仍与背景垂直居中。项目行不显示常驻展开箭头，本机文件夹图标随展开或收起切换；远程项目固定使用 16px 文件夹与右下角绿色经纬线地球的组合图标，无背景圆片，展开与收起保持形状。点击项目行只展开或折叠其任务，不离开当前对话。点击任务才打开对应对话。任务缩进，不绘制树形竖线或常驻状态点。
- 每个项目默认显示 5 条未归档、未置顶的对话；超过 5 条时提供「展开显示」，点击展示该项目全部对话，并可「收起显示」恢复前 5 条。显示数量按主机与项目分别记住，其他项目、置顶和最近列表不受影响；归档或置顶后按剩余列表补足前 5 条。
- 项目行不使用选中背景，仅保留悬停和键盘焦点反馈；当前对话仍使用选中背景。对话行背景与项目行保持相同左右边距，仅文字保留项目层级缩进。
- 对话标题前不显示会话图标。鼠标停留 350ms 或键盘聚焦后显示信息卡，包含完整标题、项目、主机和任务状态；只有实际 Agent 会话已初始化且进程仍存活时，追加「已打开」。状态由 Server 的即时投影提供，不从执行状态、历史记录或打开的页面推断；断线显示「会话状态待确认」。输入区只保留 Agent 名称，不重复显示会话已打开。
- 项目信息卡采用同样的触发与布局，展示项目名、主机、完整路径、未归档任务数和已打开会话数；统计包含置顶、折叠和未选中的会话且去重。缺少快照或实时会话证据时明确显示待确认，不伪装成零。信息卡仅复用已有数据，不触发主机初始化、会话打开或额外网络请求；离开、滚动、打开菜单或 Escape 时关闭，允许鼠标移入卡片阅读，位置受窗口边界约束。
- 项目和对话行支持右键、键盘菜单键 / Shift+F10 及省略号按钮打开操作。项目行悬停或获得键盘焦点时显示更多操作与新任务；对话行显示更多操作、置顶与归档。新任务按钮打开空白任务并选中该项目及其所属主机。远程项目显示主机名及文件夹上的远程标记；项目收起时只汇总此项目未归档、未置顶对话的状态，置顶对话的状态仅在置顶区显示，避免重复提示。按「运行中 → 等待确认 → 已完成且未读」优先显示动态省略号、暂停图标或蓝色未读圆点；多个状态共存仍只显示优先级最高的一项，已读后移除蓝点，展开后交由各对话行显示。触屏环境始终显示操作按钮。
- 对话执行中显示横向动态省略号，等待确认显示暂停图标；完成但未读显示蓝色实心圆点，读取后清除。状态指示与操作共用行右侧空间：默认显示状态，悬停、焦点在行内或菜单打开时隐藏状态并显示操作，离开且菜单关闭后恢复；触屏始终显示操作。运行和等待确认的对话禁用快捷归档，须先停止；减少动态效果设置下省略号保持静态。
- 新任务先打开未保存的空白会话，首次提交非空内容时才创建持久会话。重复新建、列表刷新、离开页面或关闭窗口均不保存未提交的空任务；切换会话后，迟到的提交响应不能抢回当前页面。
- App 完全退出后重新启动默认显示「新任务」。主机初始化、历史列表刷新和重连不自动选中第一个历史对话；用户点击历史对话后才进入它。同一次 App 运行期间，主机重连仍保留当前选择。
- 新任务的输入区提供可搜索的项目选择器。收起时本机项目仅显示文件夹、项目名和展开箭头；远程项目追加次要文字 `SSH · 主机名`，不再叠加电脑或地球图标。悬停与无障碍描述保留主机和完整路径，展开列表明确标注「本机」或 `SSH · 主机名`。切换项目时保留未发送文本，恢复所选主机与 Agent 上次手动选择的模型和思考强度，并连接所选项目的主机；首次发送只向该主机创建任务。已有任务的项目归属不可通过选择器更改。
- 项目选择器仅悬停或键盘当前项使用高亮背景，背景随当前项移动；已选项目保留勾选，不额外占用一块背景。打开列表时键盘当前项从已选项目开始。

## 组件维护约定

1. 新页面复用现有按钮、表单、Select、弹窗和菜单规则，先查 token，再决定是否确实需要新增变量。
2. 组合控件必须明确谁负责边框、焦点和圆角。外层负责时，内层输入需要显式清除背景、边框、圆角和外边距，且选择器优先级足以覆盖通用表单规则。
3. 不在文件末尾不断叠加覆盖规则，也不以 `!important` 修补普通按钮/表单颜色冲突。
4. 16px 图标与点击面积是两个概念；不能通过缩小点击区域让图标显得紧凑。
5. 显示文本变长时优先截断或换行；保留 tooltip/说明，不能挤掉关闭、发送和侧栏按钮。

## 验收

修改公共样式后至少检查创建项目、设置表单、会话右键菜单、模型选择及聊天输入；对照默认、聚焦、悬停、禁用、选中状态。用真实桌面窗口检查中文排版、圆角、Mac 窗口控制区和键盘焦点。构建检查与真实桌面验证分别记录，未验证的状态不能宣称通过。

## 模型与思考强度菜单

输入区使用一个「模型名 + 思考档位」文字选择器与单个展开箭头，档位为次要文字。
主菜单列出模型，底部独立的 `Effort` 入口打开二级菜单，勾选当前档位。
模型没有自定义名称时保留原生 ID；有自定义名称时，菜单主文字显示该名称，右侧以浅灰色
和较小字号显示 Claude 别名，输入框按钮只显示自定义名称。选择值始终保持原生 ID。
Agent 档位保留原生英文值，不翻译或改写大小写；未覆盖档位显示「跟随 Agent」，
默认模型显示 `default`。模型和强度的手动选择按主机 / Agent 保存在本机，新任务、跨项目和重启后恢复；已有会话优先使用自己的参数。选择跟随 Agent 时不注入思考强度参数或环境变量，由 Agent 读取自己的配置。模型能力刷新导致的临时强度清除不会覆盖记忆。不支持调整时禁用二级入口，触发器省略档位。
每个模型行和档位行右侧固定预留 15px 勾选图标位置，未选中时隐藏图标但保留空间，
选中状态不得挤动名称和灰色别名。
主菜单宽 200px，档位子菜单宽 140px，长模型名截断并通过 tooltip 展示完整值。
菜单使用 36px 单行选项，主列表独立滚动、底部入口固定；子菜单优先在左侧展开，
空间不足时换边并约束在窗口内。上下键移动、Enter 选择，左右键进入/返回子菜单，
Escape 逐层关闭，点击外部关闭整个选择器。

## 自定义外观

设置采用通高双栏布局，内容画布与侧栏延伸到窗口顶端，不设置横贯页面的返回栏。
返回入口位于左侧导航的设置标题下方、分类列表之前；顶部保留透明的 44px 窗口拖动区域，正文通过内边距避开。

设置中的「外观」提供系统 / 浅色 / 深色模式；系统模式监听系统偏好变化。
浅色和深色各自保存配色、字体、字重、侧边栏透明效果和层次对比度。
设置默认即时应用，编辑非当前主题时只更新预览，不影响当前工作台。
UI、正文与代码分别使用 `--font-ui`、`--font-content`、`--font-code`；终端同步
代码字体和颜色，不重建终端或重放输入。字体使用本地字体栈，缺失时使用备用字体。
半透明侧边栏是应用内部的混色和模糊效果，不代表系统桌面透视或 macOS vibrancy。
对比度滑块调节面板和分隔线与背景的层次，保留用户指定的前景/背景；低文字对比度会提示。

`appearance.ts` 从受约束的颜色、字体枚举生成现有语义 tokens，避免组件保留固定深色。
外观仅存于 WebView 的 `latte-work.appearance.v1` 本地存储，不发送到主机。
主题 JSON 包含 `version: 1`、模式和两套完整配置；导入上限 32 KB，先验证所有字段，
再一次应用。错误输入不会覆盖当前配置；存储失败明确提示，损坏或未知版本回退默认，
且不自动覆盖原数据。恢复默认仅作用于正在编辑的主题。只保留预设选择器前的「导入 / 复制主题」入口；导入直接选择 JSON 文件，校验通过后一次应用。复制将完整配置写入系统剪贴板；失败时就地报错，不展开额外文本面板。格式与示例见 [主题 JSON](themes.md)。

## 工作台布局

- 文件页只保留一条 44px 高的路径工具栏：左侧项目名与当前文件路径，右侧自动换行、文件树开关和刷新，图标统一为 16px、点击区域一致。移除重复的「项目文件」标题和「返回目录」行；点击项目名回到项目根目录并展开文件树，长路径单行省略、悬停保留完整路径，截断提示也放在同一行。文件页在未选文件和预览时都将目录放在右侧，窄工作区也不改为上下排列。未选文件时左侧显示「打开文件」，目录按需展开、标出当前文件，并可直接切换文件；提供文件树开关，收起目录不关闭预览。树与内容独立滚动，中间使用 1px 分隔线、7px 拖动区域调整目录宽度；分隔线可用左右方向键调整，Home / End 调整到上下限。保存用户选择的宽度，窗口缩小时临时约束宽度、放大后恢复。目录通常至少 160px，预览至少 120px；极窄区域优先保留两侧内容。文件预览默认自动换行，长代码和链接随预览宽度折行，保留原始行号、缩进和内容。工具栏开关记住用户选择，关闭时恢复横向滚动，切换文件或重启后沿用。文件预览不显示「只读预览」标签，仅在内容超出读取上限时提示截断。目录读取失败统一进入状态提示，可单独重试，不影响已打开的文件内容。
- 窗口标题栏只承载当前任务和少量窗口操作；其下对话画布使用轻微圆角和 8px 外缘留白；分栏时，对话滚动条紧邻右侧工作区分隔线，不保留这条边的额外留白和圆角。分隔线悬停和拖动使用中性边界色高亮，不使用品牌色。
- 工作台外层固定在窗口视口内，页面本身不滚动、不回弹。主对话和子智能体正文独立滚动，到达顶部或底部后停止，不将滚动传递到整页；输入框和侧栏保持原位。
- 左栏收起时，快捷按钮与当前对话标题之间使用 1px 宽、20px 高的中性竖分隔线；右侧会话操作 / 概览与工作区开关之间使用相同分隔线。两侧留白各 4px，不改变按钮点击区域和标题栏中线，合并工作区时保持相同分组。当前对话「…」复用侧栏会话菜单，提供重命名、置顶、未读标记、复制、停止、关闭和归档；停止仅执行中出现，关闭与归档遵循原有状态限制，未发送的空白任务禁用入口。菜单靠触发器右侧对齐，切换主机 / 对话或设置时关闭，Escape 返回触发器焦点。
- 新任务默认收起右侧工作区，通过标题栏按钮打开；已保存的可见状态、宽度和终端标签原样恢复。右侧工作区不设置固定最大宽度，拖动上限随窗口和左侧导航宽度计算，聊天区最小为 240px。窗口变小时临时约束显示宽度，放大或收起左侧导航后恢复用户保存的宽度；窄聊天区缩减两侧留白并简化输入控件。继续将分隔线拖到左侧导航边缘时，合并为主区域标签布局：对话固定在第一项，不提供关闭按钮，文件和终端标签在其后；切换标签保留草稿、阅读位置和终端实例。合并后，右上角侧栏按钮恢复「对话 + 右侧栏」布局，对话优先使用 320px 宽度；左侧导航边缘的分隔线始终只调整左栏宽度，不负责分离工作区。合并状态与选中标签按对话保存。
- 空任务保留一行标题、一行说明和紧凑的任务建议，不使用大图标、英文标语和编号卡片。聊天正文与输入框保持同一内容宽度和中线。
- 设置页继续使用通顶双栏，紧凑导航与居中的内容列分离；外观页与其他设置分类使用同一最大宽度。

## 输入区引用与 Agent 命令

- 输入区的「＋」和独立词首 `@` 打开项目文件 / 文件夹列表。当前目录内可搜索，输入 `@src/` 或进入目录继续浏览；Enter 进入文件夹，Tab 引用文件夹，也可通过「引用此文件夹」添加。
- 引用以可移除的标签展示，最多 20 项；发送时附上项目相对路径，Agent 在所属主机按需读取，不上传或复制文件内容。切换主机 / 项目清除引用，发送失败保留草稿和引用。
- 「＋」菜单底部提供工作区外引用：本机可选择文件、选择文件夹或输入绝对路径；远程仅提供「引用远程路径」，由当前远程主机校验路径。项目内路径保持相对路径，外部路径显示规范化绝对路径。引用不扩大 Agent 权限、不自动同步本机文件到远程。取消、无效路径和过期选择不添加引用。
- 输入首位 `/` 从当前项目所属主机的当前 Agent 获取原生命令列表及参数提示；展示 CLI 内置、项目和用户命令，由 App 管理的子智能体、模型及思考强度命令统一使用 App 入口，其余以原生目录为准。选择命令只填写草稿，原生命令在用户补充参数并发送后，原文经正常任务链路交给 Agent。
- 菜单支持 ↑↓、Enter / Tab、Escape、鼠标和中文输入法；选择菜单项不发送任务。浮层与输入框等宽，列表独立滚动，保持中性焦点背景。加载失败显示原因及重试按钮。
- 斜杠命令不能混入文件引用，以免引用路径改变原生命令参数。未实现的 Agent、缺少命令发现能力的 CLI 和不支持的命令明确报错。

- 斜杠菜单使用紧凑双列：命令名与说明统一对齐，主标题优先使用 Agent 展示名称，其次使用常用命令中文名、Skill 说明中的短标题或格式化名称；原始 `/命令` 作为下方的次要标识，不重复绘制斜杠图标。长说明单行省略并提供完整悬停提示；快捷键提示放在底部，菜单高度上限 320px。

- 输入框占位提示使用很浅的弱化灰色，与实际输入区分；仅混合占位色与输入区底色，不影响正文或其他表单。输入正文行高为 1.5，空白输入区按一行起始，随内容和宽度变化自动增高，最高 200px 后内部滚动。

- 目录搜索使用菜单内的 36px 轻量搜索行，配 16px 搜索图标和中性透明底；内部输入显式清除原生背景、边框和阴影，聚焦时不增加描边。

## Agent 权限

输入框上方左侧为项目选择，右侧显示当前 Agent 名称。输入框内部左侧为添加引用与权限，右侧为模型和发送；不显示「新会话」状态文字。权限与模型控件统一为 32px 高度并垂直居中，权限触发器不继承表单的顶部间距。
权限入口显示盾牌和当前权限模式。菜单沿用公共 Select，展示每项的易读名称与说明；
完全访问使用警示色，选中项保留勾选。默认「跟随 Agent」，不替换为某个推测的档位。
选项由执行主机的 Agent 适配器提供，界面不硬编码 Claude 规则；未知或加载失败时允许恢复跟随
Agent，并在权限入口旁提供中性刷新图标，悬停显示失败原因及重试说明，不自动降级或替用户切换权限。权限按主机 / Agent 记住，新任务恢复，
已有会话使用自身的权限；运行中、断线和归档时禁用切换，选择对下次发送生效。

## 输入区粘贴

- 普通文本插入光标选区；超过 8,000 字符或 200 行时转成 App 管理的 UTF-8 `.txt` 附件，不占满输入框。
- 图片、视频、文件和粘贴文本使用各自图标与类型标签；正文显示原文件名，悬停保留完整引用路径。媒体按原文件保存，不自动转码。
- 输入区的图片标签可点击放大预览，移除按钮独立操作；发送后，图片以缩略图排列在用户正文上方，文件与目录显示名称，完整路径仅放在悬停提示里。新旧引用格式都按真实附件显示，不在聊天正文展开内部 JSON。放大预览复用 Modal，Escape、关闭按钮和点击遮罩可关闭，焦点回到触发图片；切换主机／项目／对话或隐藏页面关闭旧预览。图片通过所属主机的既有来源接口读取，按实际 MIME 校验，读取失败可重试，不把路径当作图片 URL。可见图片才读取，共用最多两项读取；离开视口后释放对象 URL，已读的可见图片在断线时仍可查看。
- 发送给 Agent 的引用提示使用短说明和紧凑 JSON，仅保留路径、文件／目录类型、必要的原文件名及附件类型；继续说明相对路径基于项目、绝对路径位于当前主机并按现有权限读取。普通消息内容和保存的原始请求不改写；格式无法确认的引用块继续按原文展示。
- 剪贴板文件优先于同一次复制携带的缩略图和文件名文本。批量附件保存成功后一次添加；错误保留原草稿和剪贴板内容，避免部分结果误发送。
- 保存与远程传输时显示状态并禁用发送；切换项目、主机或会话后忽略迟到结果。本机附件在本机暂存，远程任务在传输成功后使用远程路径。已有权限设置保持不变。
- 单文件 64 MiB，合计最多 20 个引用；超限直接说明原因。粘贴本机目录只添加路径引用，远程任务提示先传输目录。

## 连续性、模态与阅读

主对话左侧提供每轮问题的轻量跳转刻度，与右侧正文滚动条分离，不占输入区。正文与输入框对称预留至少 40px 留白，刻度保留在正文外，窄列也不遮挡文字。悬停或键盘聚焦向右预览该轮问题和回复原文摘录，当前阅读轮次使用较长的亮色刻度；点击定位到问题并暂停跟随新输出，继续使用「回到最新」。方向键、Home / End 移动焦点，Enter / Space 跳转，Escape 关闭预览。预览受当前对话列的边界约束，复用浮层与文字语义变量。部分历史从轮次中间开始时不生成虚假的问题刻度；较早轮次通过分页加载，追加时保留阅读位置，切换对话不保留上一对话的刻度或预览。单轮对话不显示刻度栏。

- 会话草稿按主机和会话保留，新任务有独立草稿；仅保存在本次 App 运行的内存中。引用按主机、项目隔离。成功只清除那一版已提交草稿，失败或迟到响应不得清空后来写入的内容。发送尚未确认时主操作显示发送中并禁用，即使轮询先上报运行中也不会提前变成可点击的停止按钮。欢迎建议仅在输入为空时显示。
- Provider 表单离开设置后保留在内存中，包括尚未保存的凭据；取消明确丢弃，不写入 WebView 存储。保存按钮靠右，无修改时禁用并显示已保存。
- 所有弹窗复用 Modal：背景 inert，Tab 在当前层内循环，关闭恢复触发点。Select 浮层属于所在弹窗。Escape 逐层关闭，后台新建任务快捷键在弹窗期间暂停。
- 用户消息右对齐，使用四角一致的 16px 圆角、上下 12px / 左右 16px 留白，14px 字号和 1.65 行高；宽度随内容收缩，上限为正文宽度的 85%。每轮对话独立布局，轮次之间保持 24px 间距，即使中间没有回复也不相连。气泡下方预留一行发送时间与复制按钮，右侧对齐；悬停或键盘聚焦时显示，触屏常驻，显示时不改变布局。发送时间来自持久消息时间，完整日期保留在悬停提示中。
- 对话普通文字允许长标识符换行，代码与表格仅局部横向滚动，代码块正文 13px。执行过程不展示回复复制入口；最终答复底部保留纯图标复制及成功反馈，旁边常驻弱化的回复完成时间，使用 12px UI 字号、与发送时间相同的友好日期和本地时分格式（今天、昨天、前天；更早显示月日，跨年带年份），完整日期保留在悬停提示中。主对话使用持久化的轮次完成时间，子智能体使用已完成任务的更新时间，不使用当前渲染或过程读取时间；缺少有效时间时不补造。按本地日历日期判断，不按过去 24 小时计算；跨午夜和应用唤醒后更新友好日期。代码块保留复制。完成的 turn 默认折叠过程，只展示最后答复；展开状态绑定会话与完成记录，新完成结果重新收起，同一结果的普通刷新保留手动展开状态。用时摘要右侧使用细线展开箭头，可展开查看中间消息与工具记录；模型/Provider 启动提示不进入正文展示；执行中、等待审批、失败和状态待确认保持过程可见。确认停止后显示「已停止 · 用时…」摘要，工具过程默认折叠，已有文字和审批决定保留；不足一秒仅显示「已停止」，无工具过程时不显示展开箭头。文件改动不会撤销的说明仅保留在摘要悬停提示中。向上回看时停止跟随并显示“回到最新”，新输出到达时更新提示。
- 输入区按自身宽度简化辅助信息：先省略思考档位，极窄时仅显示权限图标与箭头；模型名和主要操作优先。完整选项仍在菜单中。工作区外引用合并为次级入口。
- 待审批操作固定在输入框上方，与聊天正文分开；多项请求显示数量并在有界区域内滚动，不随历史消息滚走。对话流仅保留可展开的一行审批记录，处理后区分允许与执行完成、失败并保留工具结果。操作区使用中性面板、柔和边框和大圆角，类型图标与标题为次要文字；正文以确认问句说明动作，内容预览弱化嵌套背景，右下角使用“拒绝 / 允许一次”胶囊按钮。明确工具 ID 对应的工具调用与审批合并展示，完整参数默认收起；无明确 ID 不猜测并行工具对应关系。断线、停止中和提交期间禁用审批；历史未就绪、已归档、已结束或已过期时不显示操作区，切换会话后不得携带前一个会话的审批。
- 模型的提问直接显示问题与选项，独立于权限审批。支持单选、多选及「其他」自填内容，不预选或自动提交；回答所有问题后才能提交，提交期间禁用交互。跳过明确表示没有回答，不生成默认答案或新 turn。待回答区与审批区共用输入框上方的有界布局，等待状态显示「等待你的回答」；断线、停止、会话切换与过期规则一致，历史只显示保存的问题与回答记录。旧主机发来的提问审批只显示服务需更新与跳过入口，不提供无答案的「允许一次」。
- 失败与状态待确认保留侧栏图标，读取不清除。连接状态分别赋色。终端配置浅深 ANSI 16 色与最低文字对比度，换主题不重建终端、不重放输入。
- 改动视图按未暂存、已暂存、未跟踪分组，列表与单文件预览均限定当前项目。加载和错误保留返回；输出有界，截断时提示，统计仅代表显示内容。

## 上下文与用量

当前回复的普通文本近期出现大量重复行时，在统一状态入口显示「回复内容似乎在重复，可停止任务后重试。」及明确的停止操作；只在连接正常、历史就绪且任务执行中显示。保留正文与现有停止入口，不自动中断。工具进展、新一轮请求、正常输出恢复、停止或任务结束后撤下提示；代码围栏、表格与引用采用保守排除。

模型左侧仅显示中性细圆环，弧长表示已上报的上下文占比，不常驻百分比或 Token 文案。

上下文采用最近一次主 Agent 请求的有效输入快照，忽略网关的零值占位；流式用量随请求结束更新，最终结果补齐本轮统计。容量仅使用明确匹配模型的 CLI 上报值，网关返回模型名不同时，关联本次显式启动或 CLI 初始化上报的模型；不能拿累计 Token 代替上下文。缺少容量时只显示已用 Token，不显示未知占比、容量占位或空进度条；尚无用量时显示「暂无用量数据」。未采集的工具用时、TTFT、TPS 不显示占位行。

- 执行状态行使用弱化文字，不带 Agent 名称；字号与正文一致，以三个点依次轻微上浮与淡入代替旋转图标，最后一个点落下后文字柔和扫亮一次，共用 3 秒循环，不重复省略号。审批与断线时三点静止，遵循减少动态效果设置。依真实阶段显示「等待响应…」「正在思考…」「正在回复…」及读取／写入／搜索／运行命令；多工具并行显示「正在执行工具…」。仅明确的思考事件可触发思考状态，不展示思考正文。审批、停止与断线状态优先，完成后状态行消失。

## Agent 会话状态与项目关闭

侧栏悬停信息卡中的会话状态只使用 Server 的实时进程证据；任务已完成不代表会话关闭。项目下的对话文字仅比项目名称向右偏 2px，不增加前置图标，行背景仍与项目保持相同左右边距。已确认没有对话的项目名称与空列表提示使用灰色，只有置顶对话的项目不视为空项目。打开和恢复时，侧栏动效只在右侧显示，与历史加载合并为一组；提示和动效显示在输入框上方居中的「回到最新」位置，与返回按钮互斥，不额外增加一行。断线显示状态待确认，不推断远程进程已停止。正常已打开状态不在输入区重复显示。旧 Server 缺少状态字段时明确提示需要更新。

本机与远程主机共用同一套初始化、连接复用与会话切换流程，仅底层传输不同。首次连接的并发请求共享握手和项目快照；同一 App 内切换已连接的主机复用现有传输。主动重连或连接失效后替换传输并恢复会话，后台主机同样自动重连，不依赖用户重新选中对话。切回已打开的会话不重复发送打开请求，已完成加载的历史在有界内存缓存中保留，按最后事件序号补取新增内容。后台状态仍由 Server 更新，Server 实例变化后清除对应主机的历史缓存。

项目操作提供关闭全部对话及实时数量，读取此项目全部会话，包括置顶和未选中的项。空闲直接关闭；运行、审批、后台任务或未确认安全状态统一确认后关闭。Server 在 actor 内再次校验空闲，避免检查后新任务被误关。当前会话被关闭后进入新任务，历史、草稿和置顶保留；部分失败展示成功及失败数量，仅重试失败项。远程文件夹右下角使用 8×8px 网络图标，约占 16px 文件夹图标面积的四分之一；普通地球角标表示远程项目，连接异常使用独立的红色感叹号形状。主机名旁不显示连接圆点，行末仅用于任务执行／等待状态与操作按钮。连接成功保留文件夹上的绿色远程角标；初次连接未确认时角标弱化为灰色，连接失败时换成红色感叹号角标。文件夹悬停与无障碍标签说明连接状态和原因，异常角标在悬停操作或项目展开时仍可见；读取历史失败不改变连接标记，同一主机的所有项目同步更新。

「最近」只向已经连接成功的主机读取历史，连接成功或替换连接后立即重读；旧连接迟到的结果不得覆盖新连接。保留已加载的记录，读取失败汇总到状态提示，列表不展示报错或技术说明。旧服务不支持最近接口时，在状态提示中说明「完整历史暂不可用」：连接正常，仍可从项目列表打开对话，更新远端服务并重新连接后自动读取，并提供连接设置入口。不显示无效重试，不误报连接失败、不推测空历史，也不重复自动请求不支持的命令。侧栏隐藏或最近分组关闭时，提示提供「查看最近」以打开读取入口，避免无效的重试。

## 子智能体

已保存的过程、工具参数、工具结果和最终回复可完整查看。长记录按页串行读取，页面可见时继续读完；全部页完成后才显示最终回复并默认折叠过程。页面隐藏时停止后续读取，重新打开继续。分页限制每次读取量，不截断正文；仅在原始记录缺失或旧缓存已丢失内容且无法恢复时提示来源不完整。


主对话正文不显示子智能体汇总卡片。子智能体的状态数量与查看入口放在顶部任务概览、工作区标签及 `/agents` 命令，过程中的真实 Agent 工具记录仍可回看。
标签沿用文件和终端的切换、关闭、合并及键盘规则；关闭标签不停止任务。
列表按已开启、完成、其他状态分组，使用中性图标、任务标题、真实状态和用时；点击任务打开独立命名标签页，保留列表页；重复点击复用同一标签。详情复用主对话的内容宽度、字体、文字与工具记录及三点执行状态行，仅去掉输入框，不重复显示标题、静态处理状态和最近工具。运行时实时显示已收到的文字、工具参数和输出，成功完成后默认折叠过程，最终输出及复制入口留在外面；可展开回看。失败、暂停和状态待确认时保留过程可见，缺少工具结果不显示成功。自动跟随新输出，向上回看后停止跟随并提供「回到最新」。可见列表独立于主对话事件刷新；详情拉取与主对话共用 650ms 间隔，进行中的读取不因任务进度更新被丢弃，刷新请求串行合并。完成时补取最终快照；隐藏或关闭标签停止定时读取，重新显示立即补读，重连保留已有记录，不停止执行。记录范围不足时明确标注，仅展示原生已上报的信息，不补造旧任务过程，也不展示内部任务标识。
断线只把正在运行的项显示为状态待确认，不推断成功或停止；主任务完成不改变后台子智能体状态。
斜杠菜单为所有 Code Agent 提供统一的「子智能体 /agents」入口；隐藏原生智能体查看命令的重复入口，其他命令仍以原生目录为准。`/list-agents`、`/tasks`、`/subagents` 及适配器声明的查看命令作为兼容别名，选择时只填入统一命令，提交时打开 Latte Work 的子智能体标签页，不调用 Agent、不创建会话或 turn、不写聊天记录。无参数时只清除命令文字并保留文件引用；带参数时也不转发，打开面板并提示不接受参数，保留草稿。任务运行中或主机断线时仍可打开面板，不触发停止；原生命令目录读取失败也不影响这个内置入口。

顶部「任务概览」提供快捷浮层，显示当前项目变更和子智能体运行/完成数量；操作进入现有面板。顶部右侧控件间距为 4px，右侧留白为 8px，保持原有按钮点击范围。来源分组、添加入口及来源预览标签页暂不提供，恢复布局时过滤旧来源标签；输入框原有文件引用和附件功能保留。Esc 关闭并返回触发按钮，方向键导航，窗口边缘与高度受限；分组边界、浮层背景和焦点复用语义变量。

每轮有文件修改时，在该轮最终回复之后显示变更卡片：文件数、总增删行数和各文件路径及增删行数。
卡片始终在执行过程折叠区之外；没有已记录文件修改的快照不占用对话空间，包括空的截断或不可用快照。非 Git 目录同样按实际文件前后内容采集；读取工具调用本身不算文件修改。查看变更及文件行打开统一的「变更」标签并选中本轮快照，重复选择复用同一标签，历史内容不随后续编辑变化。

## Git 变更审阅

「变更」工作区页默认按分支比较，左上角下拉菜单与增删统计组成一组，切换上一轮、未提交、未暂存、已暂存、已提交和分支。历史卡片选中本轮；当前对话还可查看任务净变更。所有入口复用同一个「变更」标签和同一组控件，不再显示「本任务／工作区」开关。切换范围保留并排、换行和文件列表设置。已提交二级菜单读取当前分支第一父级历史，显示真实提交标题与短 ID，可搜索已加载记录并继续读取更早的提交；每页固定同一提交链，选择后对比此提交与第一父级，首次提交对比空目录。上一轮读取当前对话最近已记录的请求快照，刷新仍读取保存的内容；没有快照时明确说明，不回退到工作区。分支模式显示当前分支与可搜索的基准分支列表；对比当前提交和基准的共同祖先，提交 ID 在本次读取内固定，不执行 fetch 或修改 Git 状态。未提交比较 HEAD 与当前文件，未暂存比較索引与当前文件，已暂存比较 HEAD 与索引。来源入口继续隐藏。

范围选择与统计采用紧凑胶囊：按钮 32px 高，不继承表单的顶部间距，外层仅增加 1px 边框。范围文字和增删数使用 14px 常规字重，垂直居中；范围到统计以及增删数之间留 4px，尾部留 8px。悬停与键盘聚焦只改变背景，不改变尺寸，禁用时继续显示已加载统计。

本轮快照、任务净变更与 Git 范围共用同一审阅组件。主体左侧按文件连续展示真实 diff，打开页面自动读第一项、从文件入口打开时定位该文件，不再先展示清单再进入原始文本。每个文件有可折叠标题、路径、状态和真实增删行数；代码显示实际原／新行号、上下文位置、未展示的未修改行数、增删底色及细侧边标记，并按已知代码类型使用适应深浅主题的词法高亮。已读取的大差异分批渲染，可继续显示全部服务端已返回的行，不在前端裁剪尾部。

右侧是可筛选、可折叠的目录树，单路径目录压缩显示，点击文件定位对应差异；键盘可聚焦、展开和折叠目录。窄页也保留左右结构，可通过工具栏隐藏目录。文件进入视口附近才读取，最多同时读取三个文件；隐藏面板后不再启动排队读取，旧轮次、主机或读取版本的结果不能覆盖新内容。离开视口的代码节点保留高度与已读缓存，回看恢复内容，切换统一／并排或换行不重复读取。工具栏保留刷新、自动换行、统一/并排视图和文件列表开关；「加载完整文件」放在更多菜单里，并受到读取上限约束，保存的回合快照不支持额外上下文。自动换行同时作用于两种视图，关闭时整个 diff 水平滚动。文件列表可隐藏；差异显示实际行号。空范围、筛选无匹配、无共同祖先、二进制、权限变化和截断均有内容说明；加载失败汇总到统一状态提示。工具栏保持紧凑、可换行，目录与代码分别滚动；范围说明在页底以单行次要文字显示，完整说明保留在悬停提示中。此页只读，不提供提交、暂存、重置或撤销按钮。暂不提供渲染预览、词级差异、空白和导入过滤、折叠全部或 git apply 操作。

上一轮由服务端按回合采集顺序查询最近已保存的快照，不依赖对话历史分页，不被旧回合的撤销事件或尚未完成的请求替换。从历史变更卡片进入时保持该请求的已保存快照，范围菜单可切到 Git 或最近一轮，再切回本轮仍读取同一请求。旧的多个本轮变更标签在恢复时合并到统一页，保留当前选中的请求。

## 链接与内置浏览器

浏览器工具栏右侧「⋯」菜单提供页面查找、缩放、打印／另存 PDF、当前网页可见区域截图、下载、历史记录和清除浏览数据。查找栏位于地址栏与网页之间，Enter / Shift+Enter 查找下一个 / 上一个，Escape 关闭；系统菜单快捷键在网页聚焦时仍有效。缩放显示实际比例，可恢复 100%。历史支持搜索、独立标签打开和删除；下载展示真实保存、失败、取消或中断状态，已保存文件提供「显示位置」。清理通过共用 Modal 确认，可分别选择网站数据、历史和已结束的下载记录；保留工作台设置、对话与已保存文件。

聊天中的 HTTP / HTTPS 链接默认在右侧工作区打开浏览器标签，普通点击重复打开当前 URL 复用标签，明确选择新标签时创建独立标签；Cmd / Ctrl 点击和中键点击使用内置标签。右键或 Shift+F10 打开应用菜单，提供内置新标签、系统浏览器和复制链接，支持方向键、Escape、窗口边界约束及焦点恢复。相对路径、非网页协议和带认证信息的 URL 不进入浏览器。

设置中的「浏览器」可即时保存「内置浏览器 / 系统默认浏览器」，重启后沿用。浏览器页提供地址、后退、前进、刷新和系统浏览器入口；沿用工作区关闭、切换、合并及尺寸规则。无项目或主机断线时仍可浏览网页。隐藏标签、侧栏、设置和应用浮层时隐藏原生网页，关闭标签及退出释放 WebView。

## 会话标题

默认标题跟随 Agent 的原生会话标题；尚无原生标题时暂用首条消息作为占位。
手动重命名同步修改原生会话，确认后更新侧栏、最近与对话标题；失败保留旧标题并显示原因。
运行中的重命名不发送消息、不创建轮次、不停止任务；关闭的会话重命名不打开 Agent。
原生会话里的手动标题优先于自动标题，外部修改的标题在后续读取时同步。新会话尚无原生
记录时保留期望标题，在创建原生会话时应用。标题同步不改变历史消息、排序或未读状态。


`/model` 与 `/effort` 是 App 的模型设置入口，分别打开输入区已有的模型主菜单和思考强度二级菜单，选项与能力、焦点、禁用状态、参数保存和后续轮次注入共用同一实现。隐藏原生目录中的重复入口，保留带命名空间的项目命令；手动输入或命令目录不可用时仍会拦截，不创建会话、turn 或聊天消息。无参数且菜单成功打开时清除命令文字并保留附件引用；带参数时打开菜单并提示在菜单选择，保留草稿。运行中、断线、模型目录未就绪或不支持强度调整时，保留草稿并说明原因，不转发到 Agent，也不触发停止。
